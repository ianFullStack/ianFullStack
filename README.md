# Ian Sandoval

Full-stack engineer working across two worlds: enterprise systems (IBM i / RPG, DB2 SQL, PHP, Node.js) and modern AI automation with TypeScript, Bun and Claude Code.

At work I introduced Claude Code to my team and automated a large share of our routine development work. At home I build agent systems that run unattended: research loops, schedulers, alerting, and the plumbing that keeps them safe.

## Selected work

| Project | What it shows |
|---|---|
| [secrets-manager](https://github.com/ianFullStack/secrets-manager) | Letting an AI coding agent use API keys without the values ever entering its context, chat history or disk. Encrypted vault, OS password pop-ups, an ssh-agent-style secrets agent with TTL and categories. |
| [telegram-claude-agent](https://github.com/ianFullStack/telegram-claude-agent) | Driving headless Claude Code from a phone: long-polling bot, one agent run per message, session resume, chat-id allowlist, budget and timeout caps, restart loop. |
| [backtest-research](https://github.com/ianFullStack/backtest-research) | How I test ideas before building them: control cohorts, matched random baselines, artifact checks, out-of-sample halves. Mostly honest negative results. |
| [db2-sql-functions](https://github.com/ianFullStack/db2-sql-functions) | Reusable DB2 SQL functions from enterprise work. |

## Stack

TypeScript / Bun / Node.js · PHP · IBM i RPG · DB2 SQL · Bash / PowerShell · Claude Code and the Claude API · Playwright · scheduled and long-running agents on Windows

## How I work

- Backtest or prototype before building.
- A claim needs a control group selected the same way as the winners.
- Secrets stay out of logs, chat and disk.
- Small, tested changes; automation that tells you when it fails.
